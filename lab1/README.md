# Лабораторная работа 2 Вариант 3

Решение на C с простой последовательностью действий: родитель передаёт команды, ребёнок делит целые числа и пишет результат в файл. Папка называется lab1 по твоему выбору; внутри ЛР 2, вариант 3.

## Запуск

Из папки лабораторной:

```sh
make
./build/parent
```

Пример ввода:

```text
results.txt
100 2 5
-7 2
```

В файле появятся строки `10` и `-3`. Ctrl+D на пустой строке завершает обычный ввод. Команда `10 0` завершает обе программы с кодом 2 без дополнительного ввода. Существующий файл результатов перезаписывается.

## Как читать код

1. `src/parent.c`: имя файла, создание каналов, запуск ребёнка, обмен командами и завершение.
2. `src/child.c`: функция `calculate` для одной команды, затем `main` с чтением строк и записью результата.
3. `src/common.c`: три небольшие функции для записи всех байтов, чтения ответа и закрытия дескриптора.
4. `src/common.h`: объявления общих функций и четыре ответа ребёнка.

В коде используются обычные `if`, `while`, `for` и функции. Проверки и действия записаны отдельно, переменные названы по смыслу. Комментарии из исходников удалены; пояснения собраны в EXPLANATION.md. Размер исходников специально не сокращается. `getline` читает строки произвольной длины, `strtok` выделяет отдельные числа, `strtol` проверяет их запись и диапазон.

Метка `cleanup` в конце `main` собирает освобождение ресурсов в одном месте. При ошибке `goto cleanup` сразу переходит туда. Это позволяет не повторять закрытие каналов в каждой ветке ошибки. Порядок работы подробнее разобран в `EXPLANATION.md`. Отчёт находится в `REPORT.md` и `report.docx`.

## Правила вычисления

Деление выполняется в типе int слева направо с усечением к нулю. Одно число возвращается без изменения. Пустая строка, неверный токен, число вне int и INT_MIN / -1 отклоняют команду. Синтаксис всей строки должен быть корректен; затем нулевой делитель имеет приоритет над арифметическим переполнением. Нулевой числитель допустим.

Имя ребёнка по умолчанию — `./build/child`, поэтому обычный запуск делается из папки проекта. Можно передать другой путь явно: `./build/parent /полный/путь/child`.

## Проверка работы

Программа собрана и проверена 1 ноября 2026 года на macOS arm64 и в Ubuntu 24.04 arm64. В evidence/ сохранены логи сборки, примеры обычного выполнения, обработки неверного ввода и деления на ноль, а также трасса strace из Linux.

Профиль системных вызовов — evidence/strace-key-lines.log, соответствие заданию — evidence/requirements-check.md.

В программе нет своего обработчика SIGINT/SIGTERM и наблюдения за ребёнком во время ожидания пользовательского ввода. Если ребёнок внешне убит в этот момент, родитель обнаружит разрыв при следующем обмене. Обычное завершение, ошибки обмена, открытие файла, нулевой делитель и ожидание ребёнка обработаны.
